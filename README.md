# A4 コラージュメーカー（プロトタイプ）

スマートフォンで6枚の写真と説明文を入力し、A4縦向きのコラージュを確認する静的Webアプリです。

## 構成

- `index.html`：画面構造
- `styles.css`：スマホ優先の見た目とA4印刷用スタイル
- `app.js`：画像選択、説明文・タイトル反映、文字サイズ、トリミング位置調整

外部ライブラリやビルド工程は使っていません。`index.html` をブラウザで開いてください。

## 使い方

1. タイトルを入力します。
2. 6個の写真枠をタップして、端末の写真を選びます。
3. 各写真の説明文を入力します。
4. 写真枠をタップして選択し、横位置・縦位置のスライダーで表示位置を調整します。
5. 必要に応じて「自動配置する」を押すと、すべての写真が中央トリミングに戻ります。

印刷ダイアログから印刷する場合は、A4・縦向きを選択してください。

## PDFとして保存する

1. 画面下部の「PDFとして保存」を押します。
2. ブラウザの印刷画面で保存先を「PDFに保存」にします。
3. 用紙サイズが **A4**、向きが **縦**、余白が **なし**（選べる場合）であることを確認して保存します。

PDF用のスタイルでは、A4プレビューだけを幅210mm・高さ297mmで出力します。写真のトリミング位置、タイトル、説明文、選択した文字サイズは、そのままPDFに反映されます。
